# Getting help

- **Learning Zevic**: the [tutorial](https://zevic-lang.github.io/en/start/) and [Coming from other languages](https://zevic-lang.github.io/en/from-other-languages/). The language is described in the [specification](https://github.com/zevic-lang/zevic/blob/main/docs/spec/zevic-spec.md).
- **Installing**: [Install](https://zevic-lang.github.io/en/install/), including the troubleshooting list.
- **Something is broken**: open a bug report in the repository where it happens (usually [`zevic`](https://github.com/zevic-lang/zevic/issues)).
- **An idea for the language**: open a "Language proposal (discussion)" issue first, then a proposal pull request. See [CONTRIBUTING.md](CONTRIBUTING.md).
- **A security problem**: see [SECURITY.md](SECURITY.md). Do not open a public issue.

日本語の資料は [公式サイト](https://zevic-lang.github.io/) にあります。
